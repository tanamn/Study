## 추천 학습 순서

- **기초 문법:** 변수, 자료형, 조건문, 반복문, 메서드
- **객체지향:** 클래스, 객체, 캡슐화, 상속, 다형성
- **자료구조:** List, Set, Map과 제네릭
- **오류 처리:** 예외 종류와 예외 처리 방식
- **데이터베이스 연계:** JDBC, SQL 바인딩, 커밋과 롤백
