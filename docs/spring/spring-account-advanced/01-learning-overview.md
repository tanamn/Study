# 1. 학습 목적

기본 과정에서 구현한 Spring Boot 계좌관리 프로그램을 바탕으로 금융 거래
업무를 분석·설계하고, MyBatis와 Spring의 주요 기능을 활용하여 심화
기능을 구현한다.

이번 과정은 단순한 프레임워크 사용법 습득보다 금융 업무의 처리 흐름,
데이터 정합성, 트랜잭션, 예외 처리 및 테스트 방법을 이해하는 데 중점을
둔다.

## 2. 학습 목표

-   금융 계좌 업무의 요구사항을 분석하고 업무 처리 절차를 정의한다.
-   입금, 출금, 계좌이체 및 거래내역 관리 기능을 설계한다.
-   MyBatis Mapper와 SQL을 이용해 데이터베이스 접근 계층을 구현한다.
-   Spring Transaction을 적용하여 금융 거래의 원자성을 보장한다.
-   동시성 상황에서 잔액과 거래 데이터의 정합성을 검증한다.
-   인증·인가, 자동화 테스트, API 문서화 및 실행 환경 구성 방법을
    익힌다.

## 3. 기본 과정과 심화 과정의 관계

  -----------------------------------------------------------------------
  구분                    기본 과정               심화 과정
  ----------------------- ----------------------- -----------------------
  목적                    Spring Boot 기본 구조와 금융 업무 분석·설계 및
                          REST API 이해           심화 구현

  주요 기능               계좌 기본 CRUD          입금, 출금, 이체,
                                                  거래내역

  데이터 접근             기본 과정에서 사용한    MyBatis Mapper 및 SQL
                          방식 복습               중심

  검증                    API 호출 및 기본 테스트 트랜잭션·동시성·예외
                                                  테스트
  -----------------------------------------------------------------------

기본 프로젝트는 학습 결과물로 보존하고, 심화 프로젝트는 별도
디렉터리에서 관리한다.

## 5. 진행 방법

각 단계는 다음 순서로 진행한다.

1.  업무 및 기술 개념 학습
2.  요구사항과 설계 문서 검토
3.  구현 대상과 처리 규칙 확인
4.  코드 작성 및 실행
5.  정상·오류 상황 테스트
6.  결과와 보완 사항 기록

상세 설계와 구현 내용은 실제 개발 과정에서 확인한 사항을 반영하여
지속적으로 보완한다.

## 6. 기술 학습 범위

-   Java 및 Spring Boot
-   Spring Web 및 Validation
-   MyBatis
-   관계형 데이터베이스와 SQL
-   Spring Transaction
-   동시성 제어와 데이터 정합성
-   Spring Security 기초
-   JUnit 및 Mockito
-   Swagger / OpenAPI
-   Docker 기반 실행 환경

실제 버전과 의존성은 프로젝트 생성 시점에 확정하고 README에 기록한다.
